# 🎨 Design by Den — Интернет-магазин UI-китов (WordPress + WooCommerce)

Коммерческий проект: разработка кастомной темы WordPress с нуля по макету Figma для продажи цифровых товаров (UI-китов, иконок, пресетов). 

> 🚧 **Статус проекта:** В активной разработке. 
> Реализованы: главная страница, каталог с AJAX-фильтрацией, страница товара, корзина. 
> В планах: оформление заказа (Checkout), личный кабинет пользователя, интеграция платежной системы.

---

## 🚀 Технологический стек

*   **Backend / CMS:** WordPress, PHP 8.0+, WooCommerce
*   **Frontend:** HTML5, SCSS (Sass), Vanilla JS (ES6+)
*   **Сборщик:** Vite + `@kucrut/vite-for-wp`
*   **Библиотеки:** Swiper.js (слайдеры)
*   **Инструменты:** Composer (автозагрузка классов)

---

## ✨ Реализованный функционал

### 🛒 WooCommerce & Каталог
*   **Кастомная тема:** Полностью написана с нуля, без использования готовых шаблонов и конструкторов.
*   **Интеграция WooCommerce:** Переопределены стандартные шаблоны (`content-product.php`, `content-single-product.php`, `archive-product.php`).
*   **AJAX-фильтрация:** Собственная система фильтрации товаров по категориям, тегам, цене и сортировке без перезагрузки страницы. Запросы к `admin-ajax.php` защищены nonce.
*   **Корзина:** AJAX-добавление, удаление и очистка товаров. Кастомный счетчик корзины, обновляющийся через фрагменты WooCommerce (cart-fragments.js).
*   **Цифровые товары:** Настроена продажа цифровых товаров (отключен выбор количества, настроены хуки для скачивания).

### 🎨 Frontend & UI
*   **Архитектура SCSS:** Стили организованы по методологии **7-1 pattern** (abstracts, base, components, pages). Дизайн-токены вынесены в переменные, адаптив — через миксины.
*   **Слайдер «Хиты продаж»:** Реализован на **Swiper.js** с кастомной пагинацией, навигацией и адаптивными брейкпоинтами.
*   **Аккордеон FAQ:** Доступный (`<details>`/`<summary>`) с плавной анимацией на чистом CSS.
*   **Кастомные компоненты:** Композитные кнопки, выпадающие фильтры, чипсы активных фильтров.
*   **Анимации:** Плавное появление элементов при скролле (Intersection Observer).

### 🛡 Безопасность и качество кода
*   Экранирование всех выводимых данных (`esc_html`, `esc_attr`, `wp_kses_post`).
*   Валидация и санитизация входящих данных (`sanitize_text_field`, `sanitize_key`).
*   Защита AJAX-запросов через `check_ajax_referer` (nonce).
*   Использование хуков и фильтров WordPress/WooCommerce (без прямого изменения ядра).

## 📁 Структура проекта

```text
design-by-den/
├── assets/
│   ├── scss/               # Исходники стилей (7-1 pattern)
│   │   ├── abstracts/      # Переменные, миксины
│   │   ├── base/           # Сброс, типографика, доступность
│   │   ├── components/     # Кнопки, хедер, футер, карточка товара...
│   │   ├── pages/          # Стили каталога, корзины, товара
│   │   └── main.scss       # Точка входа
│   ├── js/
│   │   ├── modules/        # JS-модули (слайдер, AJAX, корзина...)
│   │   ├── main.js         # Точка входа JS
│   │   └── dist/           # Скомпилированные ассеты (Vite)
│   └── img/                # Иконки, изображения
├── woocommerce/            # Переопределенные шаблоны WooCommerce
├── inc/                    # Вспомогательные PHP-файлы (если есть)
├── functions.php           # Основная логика темы
├── front-page.php          # Шаблон главной
├── archive-product.php     # Шаблон каталога
└── single-product.php      # Шаблон товара
```
